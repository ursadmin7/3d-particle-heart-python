# ❤️ 3D Particle Heart

An interactive 3D-style particle heart animation built with Python and Pygame.

## ✨ Features

- ❤️ Heart shape formed by thousands of particles
- 🔴 Glowing red and pink particle effects
- 💓 Animated heartbeat and particle shimmer
- 🔄 Interactive rotation using the mouse
- 🔍 Zoom in and out using the mouse wheel
- 🎮 Keyboard controls
- ⭐ Animated starry background

## 🛠️ Requirements

- Python 3
- Pygame

## 🚀 Installation

Install Pygame:

```bash
python -m pip install pygame
```

Clone the repository:

```bash
git clone https://github.com/ursadmin7/3d-particle-heart-python.git
cd 3d-particle-heart-python
```

Run the program:

```bash
python 3d_particle_heart.py
```

## 🎮 Controls

| Action | Control |
|---|---|
| Rotate | Hold the left mouse button and drag |
| Zoom in/out | Scroll the mouse wheel |
| Rotate horizontally | Left/right arrow keys |
| Rotate vertically | Up/down arrow keys |
| Zoom from center | `+` / `-` |
| Toggle automatic rotation | `SPACE` |
| Reset animation and camera | `R` |
| Hide/show instructions | `H` |
| Exit | `ESC` |
